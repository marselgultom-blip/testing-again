# Iklimara — Website Edukasi Perubahan Iklim (7 Halaman)

## Cara membuka
1. Ekstrak ZIP ini.
2. Buka folder `Iklimara_Website`.
3. Klik dua kali `index.html` untuk membuka beranda.
4. Untuk mengunggah ke GitHub Pages, unggah seluruh isi folder beserta `css`, `js`, dan `images` dengan struktur tetap.

## Halaman
- `index.html` — Beranda, peta materi, fakta ringkas, kuis pembuka.
- `edukasi.html` — Pengertian perubahan iklim, cuaca vs iklim, efek rumah kaca, kuis.
- `penyebab.html` — Gas rumah kaca, penyebab emisi, data global/Indonesia, penjelajah kebiasaan jejak karbon (indikator refleksi, bukan kalkulator CO2e).
- `dampak.html` — Dampak pada suhu, air, pesisir, pertanian, kesehatan, ekosistem, dan konteks Indonesia.
- `mitigasi.html` — Energi terbarukan, efisiensi, transportasi, hutan, sampah, checklist mitigasi.
- `aksi-iklim.html` — Aksi rumah/kampus/masyarakat, adaptasi, dan rencana tujuh hari.
- `tentang.html` — Tujuan, manfaat, SDG 13, serta daftar pustaka dari dokumen materi.

## Struktur
- `css/style.css` — gaya dan tata letak responsif.
- `js/main.js` — navigasi mobile, kuis, kalkulator indikator kebiasaan, progres checklist.
- `images/` — logo SVG dan foto ilustratif lokal. Foto-foto di tiap halaman berbeda.

## Catatan
Website memakai HTML, CSS, dan JavaScript biasa tanpa framework. Sebagian font dapat memakai fallback jika internet tidak tersedia. Materi dan daftar rujukan disusun dari dokumen `Pages pemweb.docx` yang diberikan. Angka dan klaim mengikuti tahun/satuan pada dokumen; perhatikan catatan bahwa sebagian angka merupakan estimasi awal atau ringkasan sekunder. Kalkulator kebiasaan tidak mengklaim menghitung emisi CO2e.
